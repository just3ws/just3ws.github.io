# The Sound Above: Season One Working Plan

This is a working outline for revisiting interviews from the UGtastic archive. Season One has a target of 17 interviews. Episodes -1 and 0 are setup pieces outside that count. Later archive records remain candidates. There is no release schedule, and the order can change.

## What each episode needs

Start with a real moment from the interview or a personal memory that can be described plainly. Give viewers enough context to follow the conversation. Ask one useful question, then let the original recording do most of the work.

After the rewatch, say what stood out or changed in your understanding. A present-day connection is optional. Avoid a required runtime, fixed act timing, preset conclusion, or promise about the next episode.

The source recording and transcript are the evidence. Check names, dates, technical terms, and claims against them. Keep recollections distinct from what the guest said. Link useful sources without turning every episode into a research report.

## Episode materials

This repository owns interview notes, episode dossiers, scripts, recording cues, thumbnails, and public series pages. The OBS baseline uses a light, low-positioned overlay that fades away so the recording stays in focus.

The local preparation tools check dossier structure, source transcript availability, OBS cue shape, and teleprompter files. They do not create YouTube descriptions, calculate publication quota, or schedule a release.

## Publishing boundary

Video uploads, captions, playlist changes, metadata updates, publication status, and YouTube quota are handled by the separate `media-pipeline` repository. The content repository does not write to YouTube.

No episodes in this rewatch series have been published yet. The local outline and the production site describe work in progress, not a release calendar.

## Episode -1 transcript count

The Fluffle source repository was audited at a tracked snapshot. It contained 1,017 matching `.txt` and `.srt` pairs, with no unmatched stems. Public-facing copy uses “1K+ transcript pairs” so the published wording remains useful as the repository grows.
