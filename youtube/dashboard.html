Editorial & SEO Invariants Guide

Title Formulation

Format: {Speaker} on {Topic} | {Event}. Keep under 70 characters when possible for mobile devices. Zero em dashes, double hyphens, or vague clickbait.

Chapter Structure

Must begin at 00:00 with an introduction chapter. Minimum 3 chapters for long-form talks. Minimum 10-second gap between successive timestamps.

Provenance & Attribution

Every description must include the 1:1 Oral History Record badge, canonical transcript link back to just3ws.com, and pre-filled GitHub issue report URL.

Captions Verification

Upload WebVTT tracks as English (Human Verified) to prevent YouTube auto-captions from degrading domain terms, names, and code syntax.
