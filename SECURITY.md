# Security policy

## Reporting a concern

Please report suspected vulnerabilities or accidental disclosure privately.
Use GitHub's private vulnerability reporting for this repository when available.
If that channel is unavailable, contact Mike through the private contact method
listed at [just3ws.com/contact](https://www.just3ws.com/contact/).

Do not include credentials, private personal information, health information,
local filesystem paths, unpublished transcripts, or private archive material in
a public issue or pull request.

## Public archive boundary

This repository contains a public website and historical archive. The following
remain outside the publication boundary:

- secrets, tokens, keys, and environment files;
- private corpus databases, logs, caches, and handoffs;
- local machine paths and operational recovery details;
- unapproved personal, workplace, or third-party private information;
- uncertain AI-assisted material that has not passed editorial review.

Please include the affected public URL or repository path, a short description,
and safe reproduction steps. Redact sensitive details from the report.

## Scope

The primary scope is the public site and repository at
`github.com/just3ws/just3ws.github.io`. Third-party services linked from the
site, including video hosts and external archive services, have their own
security and privacy policies.
